# C Star and Number Patterns

A small collection of C programs for practicing console output, loops, and pattern-building fundamentals.

## Contents

The numbered source files demonstrate star and number patterns. Each program is a separate exercise.

## Compile and run

With GCC installed, compile one source file at a time. For example:

```sh
gcc 01_num_pattern.c -o num_pattern
```

Run the generated executable from your terminal (`./num_pattern` on Linux/macOS or `num_pattern.exe` on Windows).
